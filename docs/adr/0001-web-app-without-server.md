# Веб-приложение без сервера, данные в браузере

Завхоз планирует раскладку на компьютере, а в походе нужен доступ с телефона без интернета; в v1 пользователь один и аккаунты не нужны. Поэтому приложение — SPA без бэкенда: данные лежат в IndexedDB, резервная копия — файл JSON. Отвергнуты: десктоп (Electron) плюс отдельное мобильное приложение — два кодовых пути ради одного пользователя; веб с сервером и аккаунтами — инфраструктура и приватность без пользы в v1.

Следствия: нет синхронизации между устройствами, перенос похода между ними — только файлом; очистка данных браузера уничтожает походы, поэтому экспорт обязателен, а не «приятный бонус».
