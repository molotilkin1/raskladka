# Раскладка

Планирование питания горного похода: продукты по дням и приёмам, их вес, закупка и распределение между участниками.

## Language

**Поход**:
Многодневный горный маршрут с фиксированным составом участников и датой начала.
_Avoid_: трип, мероприятие

**День**:
Один день похода, нумеруется с 1; имеет календарную дату, если задана дата начала.

**Приём пищи**:
Один из приёмов дня, для которых планируется еда: завтрак, обед, ужин, КП.
_Avoid_: слот, feeding

**КП**:
Карманное питание — порционная еда на ходу между основными приёмами.
_Avoid_: перекус, снек, snack

**Продукт**:
Товар, который закупают и несут; может быть готовым блюдом-заготовкой (суп в пакете).
_Avoid_: ингредиент, позиция, строка

**Норма**:
Количество продукта на одного человека за один приём, в единице измерения продукта.
_Avoid_: г/чел, расход, раскладка на человека

**Порций**:
Сколько раз продукт входит в приём одного дня; обычно 1.
_Avoid_: раз, количество

**Вес продукта**:
Норма × число участников × порций.
_Avoid_: граммовка, итог

**Раскладка**:
Полный план питания похода: какие продукты, в каких приёмах и в каком количестве.
_Avoid_: меню, план питания, рацион

**Меню**:
Последовательность блюд по дням без граммовок.
_Avoid_: раскладка (в значении «меню»)

**Блюдо**:
Название кушанья, подаваемого в приём; на расчёт не влияет.
_Avoid_: рецепт, состав

**Вес штуки**:
Вес одной единицы штучного продукта; нужен, чтобы пересчитать штуки в килограммы.
_Avoid_: вес единицы, граммовка штуки

**Закупка**:
Сводный список продуктов с суммарным весом на весь поход.
_Avoid_: заказ, shopping list

**Распределение**:
Назначение участникам, кто несёт и достаёт каждый продукт приёма, и формирование кучек.
_Avoid_: раздача, выдача

**Кучка**:
Набор продуктов, назначенных одному участнику на кольцо; формируется при распределении и взвешивается на весах.
_Avoid_: пайка, мешок, набор

**Упаковка**:
Фасовка закупленных продуктов в порции по дням и приёмам перед распределением.
_Avoid_: пакетирование, укладка

**Завхоз**:
Участник, отвечающий за раскладку, закупку и распределение продуктов.
_Avoid_: администратор, менеджер, пользователь

**Участник**:
Член группы похода.
_Avoid_: пользователь, человек, турист

**Кольцо**:
Участок похода со своим набором дней, своей матрицей продуктов и своей нормой.
_Avoid_: этап, сегмент

**Заброска**:
Заранее завезённая часть продуктов кольца, которая не несётся с начала похода.
_Avoid_: закладка, кэш
