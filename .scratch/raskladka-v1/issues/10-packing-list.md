# 10: Список упаковки

**What to build:** Список пакетов «день + приём → что положить» с количествами. По нему завхоз фасует продукты; отметок «упаковано» в приложении нет — упаковка остаётся физическим этапом.

**Blocked by:** 07 (Сетка раскладки и карточка приёма)

**Status:** ready-for-agent

- [ ] список пакетов по дням и приёмам, только непустые приёмы
- [ ] в пакете — продукты приёма с количеством на группу, с учётом порций
- [ ] название блюда видно в пакете, если задано
- [ ] никаких статусов, галочек и отметок «упаковано»
- [ ] тесты домена: состав пакета и количества в нём
