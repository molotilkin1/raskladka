# 04: Продукты похода

**What to build:** Завхоз ведёт список продуктов похода: название, единица измерения `г` или `шт`, для штучных — вес одной штуки. При вводе названия приложение подсказывает уже введённые в этом походе продукты, чтобы `макароны` не превращались в два разных продукта.

**Blocked by:** 01 (Каркас приложения и поход, который переживает перезагрузку)

**Status:** done

- [x] продукт создаётся с названием и единицей `г` или `шт`
- [x] для штучного продукта задаётся вес одной штуки; без него продукт помечается ошибкой, видимой в весах и закупке, а не считается нулём
- [x] при вводе названия предлагаются продукты этого похода; выбор подсказки не создаёт второй продукт
- [x] продукт переименовывается; список продуктов переживает перезагрузку
- [x] удаление продукта убирает его нормы и записи раскладки (когда они появятся)
- [x] тесты домена: единицы измерения, обязательный вес штуки для `шт`, подсказка не создаёт дубль
