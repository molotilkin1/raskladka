# 05: Резервная копия похода (JSON)

**What to build:** Завхоз выгружает поход в файл и загружает его обратно — на другое устройство или после очистки браузера. Повреждённый файл отклоняется с понятным сообщением, а не ломает хранилище.

**Blocked by:** 01 (Каркас приложения и поход, который переживает перезагрузку)

**Status:** done

- [x] экспорт сохраняет один поход в файл JSON с полем версии формата
- [x] импорт создаёт поход из файла и открывает его; данные совпадают с экспортированными
- [x] импорт повреждённого или чужого файла отклоняется с сообщением; хранилище не меняется
- [x] импорт не затрагивает другие походы в хранилище
- [x] контрактные тесты: round-trip экспорт → импорт и отказ на повреждённом файле

## Comments

Реализовано.

- Порт `TripStore` расширен методами `export`/`import` (плюс алиасы `exportTrip`/`importTrip` и др.) в `MemoryTripStore` и `IndexedDbTripStore`.
- Формат резервной копии: `{ version: 1, trip }` (`src/storage/trip-backup.ts`); разбор валидирует структуру похода, версию и кольца, при ошибках бросает `Error` с понятным сообщением.
- Экспорт сериализует один поход; импорт создаёт/обновляет только этот поход и не трогает остальные.
- UI: на экране списка походов добавлены кнопки «Выгрузить JSON» и загрузка файла JSON.
- Тесты: 49 зелёных, `npm run typecheck` и `npm run build` зелёные.
