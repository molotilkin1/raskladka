# 05: Резервная копия похода (JSON)

**What to build:** Завхоз выгружает поход в файл и загружает его обратно — на другое устройство или после очистки браузера. Повреждённый файл отклоняется с понятным сообщением, а не ломает хранилище.

**Blocked by:** 01 (Каркас приложения и поход, который переживает перезагрузку)

**Status:** ready-for-agent

- [ ] экспорт сохраняет один поход в файл JSON с полем версии формата
- [ ] импорт создаёт поход из файла и открывает его; данные совпадают с экспортированными
- [ ] импорт повреждённого или чужого файла отклоняется с сообщением; хранилище не меняется
- [ ] импорт не затрагивает другие походы в хранилище
- [ ] контрактные тесты: round-trip экспорт → импорт и отказ на повреждённом файле
