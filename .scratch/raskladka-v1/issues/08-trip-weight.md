# 08: Вес похода, кольца и заброски

**What to build:** Итоговые веса: по кольцу, по походу и отдельно вес заброски. Рядом — справочный индикатор «вес / участники / дни» по кольцу и походу, чтобы завхоз замечал забытые дни.

**Blocked by:** 07 (Сетка раскладки и карточка приёма)

**Status:** ready-for-agent

- [ ] вес кольца — сумма весов его записей
- [ ] вес похода — сумма весов колец
- [ ] вес заброски показан отдельно от веса стартовых колец
- [ ] индикатор «вес / участники / дни» показан по кольцу и по походу
- [ ] изменение нормы, числа порций или числа участников сразу меняет итоги
- [ ] тесты домена: итоги по кольцу и походу, разделение веса заброски, индикатор на человека в день
