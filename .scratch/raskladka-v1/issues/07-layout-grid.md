# 07: Сетка раскладки и карточка приёма

**What to build:** Завхоз вводит раскладку сеткой «продукты × дни», сгруппированной по приёмам: клетка — число порций продукта в приёме дня. Карточка приёма показывает и правит один приём: название блюда, состав, добавление и удаление продуктов. Вес считается по записи, приёму и дню.

**Blocked by:** 06 (Нормы кольца)

**Status:** ready-for-agent

- [ ] сетка показывает дни 1..N и продукты кольца, сгруппированные по приёмам
- [ ] в клетке задаётся целое число порций ≥ 1; пустая клетка значит, что продукта в приёме нет
- [ ] в карточке приёма видно блюдо и состав; продукт добавляется и удаляется
- [ ] у приёма можно задать название блюда — необязательное, на расчёт не влияет
- [ ] вес записи = норма × число участников × порций; для штучного продукта — с весом штуки
- [ ] вес виден по записи, приёму и дню
- [ ] запись без нормы или штучный продукт без веса штуки помечаются ошибкой, а не дают молча нулевой вес
- [ ] тесты домена: формула веса, порций больше одной, штучный продукт, ошибка отсутствующей нормы
