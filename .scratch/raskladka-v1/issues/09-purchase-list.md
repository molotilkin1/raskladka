# 09: Закупка

**What to build:** Сводный список закупки «продукт → количество и суммарный вес» по всему походу, чтобы завхоз шёл в магазин с одним списком. Штучные продукты показаны штуками и килограммами, количество можно поправить вручную, список копируется в буфер для чата группы.

**Blocked by:** 08 (Вес похода, кольца и заброски)

**Status:** ready-for-agent

- [ ] список закупки агрегирует все записи раскладки по продукту
- [ ] штучный продукт показан штуками и килограммами; весовой — в граммах и килограммах
- [ ] ручная правка количества переопределяет расчётное и сохраняется; вес раскладки при этом не меняется
- [ ] кнопка копирует список в буфер обмена в виде, пригодном для отправки в чат группы
- [ ] правки закупки восстанавливаются после перезагрузки
- [ ] тесты домена: агрегация по продукту, учёт ручной правки, пересчёт штук в килограммы
