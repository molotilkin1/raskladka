# 01: Каркас приложения и поход, который переживает перезагрузку

**What to build:** Завхоз открывает приложение, видит список походов и создаёт поход с названием, датой начала и числом дней. Поход сохраняется автоматически и открывается после перезагрузки страницы; если браузер не смог записать данные, завхоз видит предупреждение, а не теряет поход молча. Тикет несёт каркас: приложение, доменный модуль, порт хранилища с двумя реализациями.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] приложение собирается и запускается; стартовый экран — список походов, из него создаётся поход
- [ ] поход создаётся с названием, датой начала и числом дней ≥ 1; число дней задаёт дни 1..N и календарную дату каждого дня как «дата начала + (номер − 1)»
- [ ] созданный поход появляется в списке, открывается и после перезагрузки страницы остаётся на месте
- [ ] изменения похода сохраняются автоматически, без кнопки «сохранить»
- [ ] ошибка записи в хранилище показывается завхозу
- [ ] порт хранилища покрыт одним набором контрактных тестов, который проходит и на IndexedDB-адаптере, и на in-memory фейке
- [ ] есть интеграционный тест через корень приложения: создание похода и его появление в списке
- [ ] доменный модуль — чистый TypeScript: без React, без обращений к хранилищу, без `Date.now()` внутри расчётов
- [ ] интерфейс на русском
