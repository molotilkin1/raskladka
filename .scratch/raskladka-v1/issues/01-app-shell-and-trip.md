# 01: Каркас приложения и поход, который переживает перезагрузку

**What to build:** Завхоз открывает приложение, видит список походов и создаёт поход с названием, датой начала и числом дней. Поход сохраняется автоматически и открывается после перезагрузки страницы; если браузер не смог записать данные, завхоз видит предупреждение, а не теряет поход молча. Тикет несёт каркас: приложение, доменный модуль, порт хранилища с двумя реализациями.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] приложение собирается и запускается; стартовый экран — список походов, из него создаётся поход
- [x] поход создаётся с названием, датой начала и числом дней ≥ 1; число дней задаёт дни 1..N и календарную дату каждого дня как «дата начала + (номер − 1)»
- [x] созданный поход появляется в списке, открывается и после перезагрузки страницы остаётся на месте
- [x] изменения похода сохраняются автоматически, без кнопки «сохранить»
- [x] ошибка записи в хранилище показывается завхозу
- [x] порт хранилища покрыт одним набором контрактных тестов, который проходит и на IndexedDB-адаптере, и на in-memory фейке
- [x] есть интеграционный тест через корень приложения: создание похода и его появление в списке
- [x] доменный модуль — чистый TypeScript: без React, без обращений к хранилищу, без `Date.now()` внутри расчётов
- [x] интерфейс на русском
