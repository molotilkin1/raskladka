# 03: Кольца и заброска

**What to build:** Поход делится на кольца с диапазонами дней, у кольца есть флаг «завозится заранее». По умолчанию новый поход — одно кольцо на все дни, чтобы простой поход не требовал настройки.

**Blocked by:** 01 (Каркас приложения и поход, который переживает перезагрузку)

**Status:** ready-for-agent

- [ ] новый поход получает одно кольцо, покрывающее дни 1..N
- [ ] завхоз меняет первый и последний день кольца, добавляет и удаляет кольца
- [ ] кольцо помечается как заброска и обратно
- [ ] кольца с пропуском или пересечением дней не сохраняются; завхоз видит, какие дни не покрыты
- [ ] кольца восстанавливаются после перезагрузки
- [ ] тесты домена: полное покрытие, пропуск дня, пересечение, одно кольцо по умолчанию
