# 03: Кольца и заброска

**What to build:** Поход делится на кольца с диапазонами дней, у кольца есть флаг «завозится заранее». По умолчанию новый поход — одно кольцо на все дни, чтобы простой поход не требовал настройки.

**Blocked by:** 01 (Каркас приложения и поход, который переживает перезагрузку)

**Status:** done

- [x] новый поход получает одно кольцо, покрывающее дни 1..N
- [x] завхоз меняет первый и последний день кольца, добавляет и удаляет кольца
- [x] кольцо помечается как заброска и обратно
- [x] кольца с пропуском или пересечением дней не сохраняются; завхоз видит, какие дни не покрыты
- [x] кольца восстанавливаются после перезагрузки
- [x] тесты домена: полное покрытие, пропуск дня, пересечение, одно кольцо по умолчанию
