# 11: Распределение и кучки

**What to build:** Завхоз назначает каждый продукт приёма одному участнику и может назначить продукт массово на всё кольцо. Из назначений складывается кучка участника на кольцо; измеренный вес кучки вводится вручную и необязателен. Видно, какие продукты кольца ещё никому не назначены.

**Blocked by:** 07 (Сетка раскладки и карточка приёма), 02 (Участники похода)

**Status:** ready-for-agent

- [ ] каждая запись раскладки назначается ровно одному участнику; деления продукта между людьми нет
- [ ] продукт назначается массово на все свои записи в кольце одним действием
- [ ] кучка участника на кольцо показывает состав — назначенные ему продукты
- [ ] измеренный вес кучки вводится вручную, необязателен и сохраняется
- [ ] видно, какие продукты кольца ещё никому не назначены
- [ ] удаление участника, у которого есть назначения, требует подтверждения и удаляет его назначения
- [ ] приложение не рассчитывает вес на участника — только состав кучки и введённый вручную вес
- [ ] назначения и кучки восстанавливаются после перезагрузки
- [ ] тесты домена: назначение, массовое назначение на кольцо, состав кучки, список неназначенных продуктов
