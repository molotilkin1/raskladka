# 06: Нормы кольца

**What to build:** Для каждого кольца завхоз задаёт норму продукта на человека по приёмам. Норма живёт на связке «кольцо + продукт + приём» и применяется ко всем дням кольца, поэтому её не нужно вводить 13 раз. У одного продукта нормы на завтрак и на ужин могут различаться, как и нормы одного продукта в разных кольцах.

**Blocked by:** 03 (Кольца и заброска), 04 (Продукты похода)

**Status:** done

- [x] для выбранного кольца показана матрица «продукт × приём»
- [x] норма задаётся в единице измерения продукта — граммах или штуках
- [x] одна норма действует на все дни кольца
- [x] норма одного продукта может отличаться по приёмам и по кольцам
- [x] нормы восстанавливаются после перезагрузки
- [x] тесты домена: норма находится по связке «кольцо + продукт + приём», разные кольца дают разные нормы
