# 02: Участники похода

**What to build:** Завхоз ведёт список участников по именам: добавляет, переименовывает, удаляет. Число участников — источник числа людей для всех расчётов веса.

**Blocked by:** 01 (Каркас приложения и поход, который переживает перезагрузку)

**Status:** ready-for-agent

- [ ] участник добавляется по имени; пустое имя не принимается
- [ ] участник переименовывается
- [ ] участник удаляется; пока назначений нет, удаление не требует подтверждения
- [ ] список участников и их число восстанавливаются после перезагрузки
- [ ] число участников доступно расчётам как длина списка участников
- [ ] тесты домена: добавление, переименование и удаление меняют число участников
